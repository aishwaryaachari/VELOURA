**VELOURA** (also stylized as **velora**) is an elegant e-commerce web application for beauty and skincare products. Experience beauty that feels like you with our carefully curated collections, driven by a robust RESTful Java backend.

## 🌟 Overview

Veloura brings nature's finest energies straight to your skincare routine. The application features a stunning frontend design with modern aesthetics like glassmorphism and a seamless shopping experience. It's fully backed by a Java EE RESTful API to manage the product catalog seamlessly.

### Collections
- **Serums** - Targeted care, visible glow.
- **Moisturizers** - Deep hydration, lasting softness.
- **Cleansers** - A fresh start, every day.
- **Skincare Sets** - Complete rituals for radiant skin.

## ✨ Features
- **Modern UI**: Clean and aesthetically pleasing responsive design with glassmorphism, smooth animations, and a natural aesthetic.
- **RESTful API Backend**: Full CRUD operations for product inventory management (Add, Edit, Update Stock, Delete).
- **Dynamic Content**: Products are fetched and rendered live from the database via REST endpoints.
- **Interactive UI Components**: Beautiful overlays, live toast notifications, and interactive modals for inventory management.

## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3 (Vanilla), Vanilla JavaScript
- **Backend**: Java, Java EE (JAX-RS / Servlet)
- **Database**: SQL / Database Integration via Java
- **IDE**: Apache NetBeans

## 📥 How to Run
1. Clone or download this repository.
2. Open the project folder (`Veloura`) in **Apache NetBeans**.
3. Ensure a Java EE compatible application server is configured (e.g., GlassFish or Apache Tomcat).
4. **Clean and Build** the project to generate the `Veloura.war` deployment file.
5. Click **Run** (`F6`) to deploy the application and open it in your web browser!

## 📜 Development Notes
VELOURA was built to demonstrate full-stack web application concepts, including:
- Frontend DOM manipulation and dynamic grid rendering using JavaScript.
- Async `fetch` API integration for HTTP methods (GET, POST, PUT, PATCH, DELETE).
- Styling with CSS Grid/Flexbox and UI interactions without external libraries.
- RESTful web service creation using standard Java web technologies.
