# VELOURA

Veloura (also stylized as **velora**) is an elegant e-commerce web application for beauty and skincare products. 

## Features

- **Modern UI**: Clean and aesthetically pleasing responsive design with glassmorphism, smooth animations, and a natural aesthetic.
- **Product Catalog**: Browse featured products and view details across categories (Serums, Moisturizers, Cleansers, Skincare Sets).
- **RESTful API**: Supports CRUD operations on the product inventory:
  - Add new products
  - Edit product details
  - Update stock quantities
  - Delete products
- **Java EE Backend**: Built with standard Java web technologies.

## Structure

- `/web`: Contains the frontend assets (HTML, CSS, JS, Images).
- `/src`: Backend source code (Java).
- `/build` & `/dist`: Compiled outputs and the `.war` deployment file.

## Setup & Running

This project is configured as a NetBeans web application.

1. Open the project in Apache NetBeans.
2. Ensure you have a Java EE compatible server configured (e.g., GlassFish or Apache Tomcat).
3. Clean and build the project to generate the `Veloura.war` file.
4. Run the project to deploy it to the configured server.

## Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript.
- **Backend**: Java / Java EE (NetBeans project structure).
- **Design Elements**: Google Fonts (Cormorant Garamond, DM Sans, Playfair Display).
